# 🚀 XAMPP Dashboard

لوحة تحكم عصرية وجميلة لإدارة مشاريع **XAMPP وLaravel** بسهولة من خلال واجهة واحدة، مع مجموعة من الأدوات والإجراءات السريعة التي تساعدك على تشغيل المشاريع والوصول إلى ملفاتها وفتحها باستخدام محررات الأكواد المختلفة.

تم تصميم لوحة التحكم بواجهة عربية **RTL** مع تصميم حديث وتأثيرات بصرية وحركات سلسة، مع إمكانية تخصيص الإعدادات والمسارات بما يتناسب مع جهازك.

## الكود يتضمن بالفعل إجراءات للتعامل مع Explorer وVS Code وGit Bash وAntigravity والمتصفح، بالإضافة إلى إدارة الملفات والمجلدات.

## 🖥️ المتطلبات

قبل استخدام لوحة التحكم، تأكد من توفر:

* Windows.
* XAMPP.
* Apache يعمل بشكل صحيح.
* PHP متوفر من خلال XAMPP.
* مشاريعك موجودة داخل:

```text
C:\xampp\htdocs\project
```

ويُفضّل تثبيت الأدوات التالية للاستفادة من جميع المميزات:

* Visual Studio Code
* Git Bash
* Antigravity IDE

> بعض المميزات تعتمد على وجود البرامج السابقة في المسارات المحددة داخل الإعدادات.

---

## 📥 طريقة التثبيت

### 1. تحميل المشروع

قم بتحميل أو Clone المشروع إلى جهازك.

بعد تحميل الملفات ستجد ملف لوحة التحكم:

```text
index.php
```

بالإضافة إلى أيقونة المشروع:

```text
ico.ico
```

---

### 2. الوصول إلى مجلد XAMPP Dashboard

افتح المسار التالي:

```text
C:\xampp\htdocs\dashboard
```

إذا لم يكن مجلد `dashboard` موجودًا، قم بإنشائه.

---

### 3. إعادة تسمية ملف XAMPP الأصلي

داخل مجلد:

```text
C:\xampp\htdocs\dashboard
```

ستجد ملف:

```text
index.html
```

قم بإعادة تسميته إلى:

```text
index_old.html
```

**لا تقم بحذف الملف الأصلي**، لأن إعادة تسميته تسمح لك بالاحتفاظ به كنسخة احتياطية.

---

### 4. نقل ملفات المشروع

قم بنقل الملفات التالية إلى:

```text
C:\xampp\htdocs\dashboard
```

بحيث يصبح شكل المجلد تقريبًا:

```text
C:\xampp\htdocs\dashboard
│
├── index.php
├── ico.ico
└── index_old.html
```

الأيقونة `ico.ico` مستخدمة كـ favicon للوحة التحكم من داخل `index.php`.

---

## ⚙️ إعداد المشروع

بعد نقل الملفات، افتح ملف:

```text
index.php
```

وابحث عن قسم:

```php
class Config
```

ستجد إعدادات مثل:

```php
const PROJECTS_PATH = 'C:\\xampp\\htdocs\\project';

const VSCODE_PATH = 'C:\\Users\\%USERNAME%\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe';

const GIT_BASH_PATH = 'C:\\Program Files\\Git\\git-bash.exe';

const ANTIGRAVITY_PATH = 'C:\\Users\\%USERNAME%\\AppData\\Local\\Programs\\Antigravity IDE\\Antigravity IDE.exe';

const LOCALHOST_URL = 'http://localhost/project';
```

هذه المسارات هي المسؤولة عن تحديد مكان المشاريع والبرامج الخارجية التي تستخدمها لوحة التحكم.

### مسار المشاريع

بشكل افتراضي، يجب أن تكون مشاريعك داخل:

```text
C:\xampp\htdocs\project
```

مثال:

```text
C:\xampp\htdocs\project
│
├── LaravelProject1
├── LaravelProject2
├── MyWebsite
└── TestProject
```

يتم اكتشاف مشاريع Laravel من خلال وجود الملفين:

```text
artisan
composer.json
```

داخل مجلد المشروع.

## ▶️ تشغيل لوحة التحكم

بعد التأكد من تشغيل **Apache** من XAMPP، افتح المتصفح وانتقل إلى:

```text
http://localhost/
```

ستظهر لك لوحة التحكم بدلًا من صفحة XAMPP Dashboard الافتراضية.

## 🚀 استخدام لوحة التحكم

### تشغيل مشروع Laravel

إذا كان المشروع يحتوي على:

```text
artisan
composer.json
```

سيظهر زر **تشغيل**.

عند الضغط عليه، تقوم لوحة التحكم بتشغيل:

```bash
php artisan serve
```

داخل مجلد المشروع.

---

### 🌐 فتح المشروع في المتصفح

يمكنك فتح المشروع مباشرة من خلال زر:

**فتح في المتصفح**

وتقوم اللوحة بإنشاء رابط المشروع اعتمادًا على:

```text
http://localhost/project
```

الموجود في إعدادات `LOCALHOST_URL`.

---

### 📂 فتح مجلد المشروع

زر **فتح المجلد** يقوم بفتح مجلد المشروع مباشرة باستخدام Windows Explorer.

---

### 💻 VS Code

يمكنك فتح المشروع مباشرة في Visual Studio Code من خلال زر:

**VS Code**

ويتم استخدام المسار المحدد في:

```php
VSCODE_PATH
```

كما يمكن فتح ملف محدد من مستعرض الملفات مباشرة داخل VS Code.

---

### ☄️ Antigravity

يمكنك فتح المشروع أو ملف محدد باستخدام **Antigravity IDE**.

يتم تحديد مسار البرنامج من خلال:

```php
ANTIGRAVITY_PATH
```

وتدعم اللوحة أيضًا فتح الملفات الموجودة داخل المشروع مباشرة باستخدام Antigravity.

## 🔐 الأمان

يحتوي المشروع على بعض إجراءات الحماية، منها:

* CSRF Token للتحقق من الطلبات.
* تنظيف أسماء المشاريع.
* تنظيف المسارات النسبية.
* منع استخدام `..` للخروج من مجلد المشروع.
* التحقق من أن المسار المطلوب يقع داخل مجلد المشروع.
* التحقق من وجود الملفات والمجلدات قبل تنفيذ العمليات.

ويتم التحقق من CSRF Token قبل تنفيذ عمليات POST.

## 🛠️ تخصيص الإعدادات

يمكنك تعديل المسارات الموجودة في `Config` حسب إعداد XAMPP والبرامج الموجودة على جهازك.

مثال:

```php
class Config
{
    const PROJECTS_PATH = 'C:\\xampp\\htdocs\\project';

    const VSCODE_PATH =
        'C:\\Users\\%USERNAME%\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe';

    const GIT_BASH_PATH =
        'C:\\Program Files\\Git\\git-bash.exe';

    const ANTIGRAVITY_PATH =
        'C:\\Users\\%USERNAME%\\AppData\\Local\\Programs\\Antigravity IDE\\Antigravity IDE.exe';

    const LOCALHOST_URL = 'http://localhost/project';
}
```

إذا كان لديك مسار مختلف للمشاريع، قم بتعديل `PROJECTS_PATH`.

وإذا كان VS Code أو Git Bash أو Antigravity مثبتًا في مسار مختلف، قم بتعديل المسار الخاص به.

## ⚠️ ملاحظات مهمة

* المشروع مصمم للعمل على **Windows + XAMPP**.
* يجب تشغيل Apache حتى تتمكن من الوصول إلى لوحة التحكم من المتصفح.
* تأكد من أن مجلد المشاريع هو:

```text
C:\xampp\htdocs\project
```

أو قم بتعديل `PROJECTS_PATH`.

* بعض وظائف فتح البرامج تعتمد على `shell_exec` وأوامر Windows.
* يجب أن تكون البرامج الخارجية مثبتة في المسارات الصحيحة حتى تعمل أزرار VS Code وGit Bash وAntigravity.
* لا تحذف `index_old.html` إذا كنت تريد الاحتفاظ بنسخة من صفحة XAMPP الأصلية.
